# Sniddle

A snail game for one family's kids: Android and iPhone/iPad, no ads, no
network, no permissions. The [README](README.md) is the full guide (rules, how
it's built, linters); this file is what to remember while changing it.

## Modules

- `game/`: Kotlin Multiplatform, no Android or UI code. Rules, AI, drawing
  (through `Canvas2D`) and synthesized sound.
- `composeApp/`: the screens, Compose Multiplatform, shared by both apps.
  `androidMain` and `iosMain` hold what each platform does its own way.
- `app/`: the Android app around it. `iosApp/`: the iPhone app around it,
  generated by XcodeGen from `project.yml` (nobody here has a Mac; CI builds it).
- `build-logic/`: the `sniddle.quality` convention plugin. Every module applies
  it, last in its `plugins` block: compiler warnings as errors, detekt, Android
  Lint, JDK 21. A new module applies it too.

## Before committing

```sh
./gradlew lintAll
./gradlew :game:test :composeApp:testAndroidHostTest :app:testDebugUnitTest
./gradlew :game:compileTestKotlinIosArm64 :composeApp:compileTestKotlinIosArm64
scripts/lint-shell.sh
```

The iOS tasks only compile here. Linking or running iOS code needs a Mac and
fails on purpose anywhere else; the macOS CI jobs do it.

## Conventions

- Gameplay numbers live in `game/.../GameConfig.kt` (detekt's MagicNumber
  enforces it outside drawing, sound and UI code). After changing one, run
  `./gradlew :game:test :game:balanceReport`.
- `GoldenHashTest` pins a fixed-seed game. A change that alters the sim on
  purpose updates its hash in the same commit, and says so.
- Something kids will notice gets a line in `ui/News.kt`, with the next number.
- Saved data must survive an update: never rename a stored key (see `Storage`).
- Every rule switched off or loosened is explained next to the setting.
- Commit subjects say what changed for the player or the project, in plain
  words, not which files were touched.

## Releases

Every push to `main` that passes CI and changes the app publishes a release
the family's phones pick up. Work on a branch; anything that is only docs,
lint config or CI belongs in the skip list in `.github/workflows/build.yml`
("Check whether the app changed").
